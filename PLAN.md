# PLAN: Grohnpetrel SEO challenge (Guillemots)

Today is 31 Oct 2026. Presentations are 26 Nov or 3 Dec. Assumption: the 17 days run to about 17 Nov. After that we freeze changes, and the rest is presentation prep.

Several teams (Seagulls, Puffins, Gannets, and so on) compete for the same invented term "Grohnpetrel". Nobody owns the term, so the winner is whoever gets crawled first, is clearest about what "Grohnpetrel" is, and earns the most links and mentions. Speed and distinctiveness matter more than volume.

Marking (from the slides): 80% presentation (results and analysis 30, strategy 20, reflection 15, communication 15), 20% project log. The log must be kept as we go. A log written afterwards will not get full marks.

## Day 1 (31 Oct): get discovered

1. Fix the blocking defects in the drafts (see `pages/`): front page has no H1, three dead buttons, stray asterisks, "Accidental Fishing" is not a heading, empty trailing heading.
2. Fill the SEO / AEO / GEO Lab page with a minimum viable version, or leave it out of the menu for now.
3. Set slugs so the existing internal links resolve.
4. Publish all pages. Check Settings → Reading: "Discourage search engines" must be off. Menu must link every page.
5. Install an SEO plugin and generate `sitemap.xml`. Confirm `robots.txt` allows crawling.
6. Verify the site in Google Search Console, submit the sitemap, and request indexing for the front page and the main pages. Also do Bing Webmaster Tools. Set up Google Analytics.
7. Record the baseline: searches for "Grohnpetrel" on Google, Bing and DuckDuckGo, and which competitor sites appear.
8. Start the log entry in the Teams channel (action, date, reason, outcome).

## Days 2-4: polish content

- One clear definition sentence on the front page and "What is Grohnpetrel?", using the same wording everywhere.
- A unique title tag, meta description, single H1 and heading hierarchy per page. Descriptive image alt text.
- Internal links between all pages. Fix remaining thin pages (Mission, Knowledge Centre).
- Add real sources and cite them. Write the About page: team, origin of the name, university, Bremen.
- Check speed and mobile layout.

## Days 5-17: iterate, one change at a time

Make one change at a time and log it, so we can say what worked. Candidate experiments, roughly in priority order:

1. Backlinks and mentions: ask the course, the university site, team members' profiles and personal pages, and social accounts to link to the site. This is probably the strongest lever against rival teams.
2. Structured data: FAQPage, Organization, Article, BreadcrumbList. Test with the Rich Results Test.
3. GEO: FAQ and short direct-answer paragraphs. Test whether ChatGPT, Gemini, Perplexity and Copilot cite or mention us when asked about Grohnpetrel.
4. Long-tail pages for related terms (for example "Grohnpetrel FAQ", "Grohnpetrel programmes") so we rank for more than the bare term.
5. Entity consistency: same name, description and team across the site, social profiles and any listings.
6. New content on a regular schedule, to look maintained.
7. Technical: Core Web Vitals, canonical URLs, no duplicate or orphan pages, no leftover auto-created duplicates in the site.

## Every day

- Search "grohnpetrel" (and variants) in Google, Bing and DuckDuckGo, from different locations (VPN, different team members' countries). Record the position of our site and of each rival team.
- Check Search Console: indexing status, impressions, clicks, average position, errors.
- Ask a few AI assistants about Grohnpetrel and note whether we are cited.
- Write the log entry for the day.

Keep a daily results table (date, engine, location, our rank, top competitor, AI citation yes/no). The Results and Analysis marks are the biggest block, and this table is the evidence for them.
